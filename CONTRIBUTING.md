# Contributing

Open an issue with the goal, operating system, Python version, and reproducible
steps. Never attach credentials or unreviewed install logs. For a module bug,
use that module's tracker; for routing, install, or update bugs, use this one.

Keep changes focused. Installer changes need failure-path tests and a clean
install from the public pinned artifacts. Run the README development checks.
New modules need a public release, clear license, portable setup contract,
offline probe, and documented scope. Preserve independent versioning.
