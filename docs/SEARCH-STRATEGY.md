# Search positioning evidence

Collected 2026-09-23 through Legends GitHub and DataForSEO Kit v0.1.0.
United States (2840), English, desktop organic SERPs, depth 10.
22 keyword candidates across two batches; six exact search-result queries.
Provider-reported total cost: $0.03756. No measured ranking or traffic uplift.

## Positioning decision

Lead with agent skills and tool management for the Legends ecosystem. This
matches the central instruction router, curated installer and isolated runtimes.
The product is not an unrestricted third-party skills marketplace or an AI model.

Unreturned phrases, including agent skills manager and skill installer, have
unknown volume, not zero. Keyword estimate timestamps range September 12-17 in
the first batch; collection time is not the underlying metric update time.

## Observed search intent

`agent skills` returned a GitHub skill collection and platform documentation.
`agent skills manager` and `ai agent skills manager` returned manager projects,
including github.com/umutbozdag/agent-skills-manager and
 github.com/xingkongliang/skills-manager. Their presence establishes category
relevance, not feature superiority or attainable ranking for this repository.
`install agent skills` returned instructional documentation, supporting the new
installation explainer. `skill installer` overlapped host-specific skill tools.
`open source agent tools` returned framework and orchestration content, so it
was rejected as the primary positioning.

## Applied and measurable

Updated the banner subtitle, README opening and installation heading; added an
agent skills explainer. Selected descriptive repository topics rather than
machine-generated word pairs. Keep the six-host scope and actual limitations.
Raw provider responses and receipts are retained in the maintainer's research
archive. No competitor feature claims were inferred from search snippets.

After a comparable observation period, inspect available GitHub traffic and
referrers and repeat the exact category SERPs. Record unavailable analytics as
unknown. Publishing these changes is not evidence of improved rankings.
