# Release verification: 0.5.0

This release adds explicit startup discovery. Package installation, instruction
loading, workflow selection and task completion are separate claims.

## Automated checks

The offline suite covers routing, verified installations, safe extraction,
rollback, host registration and startup setup. Startup tests exercise preview,
existing-file preservation, edited blocks, stale indexes, restoration, path
aliases, and concurrent operations. The installed-wheel CLI rehearsal applies
and restores a temporary instruction file without changing user configuration.

CI builds and installs the package on Windows, Linux and macOS with Python 3.10
and 3.13. It installs managed modules, checks their actual recipe handoffs and
exercises report browser readiness. Obsidian is installed on Python 3.13;
unsupported Python versions are rejected before installation.

## Native acceptance observations

A fresh MetaMuse R3401.1 run received an ordinary request for music, local
visibility, research storage and GitHub improvement. The request named no
Legends products. Its first tool action read the startup capability index,
followed by the central recipe and the selected module instructions.

That verifies discovery in this tested configuration, using MetaMuse's default
import of personal Codex instructions inside its Linux execution environment.
It does not establish a native MetaMuse global-file standard or prove paid
research, music generation, or real-vault writes. The run reported missing task
inputs, unavailable credentials and uninstalled audio tooling explicitly.

The inspected Gemini host was Antigravity, not Gemini CLI. Its launcher used an
isolated configuration directory and did not load the normal Gemini skill
registration. Treat that as a separate adapter and delivery problem, not a
successful Gemini discovery test. See [startup contracts](STARTUP.md).

No paid provider calls or real-vault writes are required for these checks.
The release receipt records the final commit, CI results and artifact hashes.
Filesystem registration alone is never reported as autonomous discovery.
