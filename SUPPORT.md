# Support

## Questions and usage

Start with `README.md`, `docs/AGENT-SKILLS.md`, `docs/CAPABILITY-DISCOVERY.md`, `docs/AGENT-HOSTS.md`, and `docs/STARTUP.md`. Run `cto-legends doctor`, `cto-legends status`, and `cto-legends check-updates` to inspect your local manager state before opening an issue.

For community discussion and access to the optional AI Marketing Hub Home system, visit [AI Marketing Hub Pro](https://www.skool.com/ai-marketing-hub-pro/about).

## Bug reports

Open a GitHub issue using the bug report template with the `cto-legends` version, OS, Python version, agent host, and sanitized command output. Never include API keys, tokens, or private workspace paths.

## Security issues

Do not open public issues for suspected security vulnerabilities. Follow the private reporting instructions in `SECURITY.md`.
