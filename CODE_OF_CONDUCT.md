# Code of Conduct

Participation in this project is governed by a commitment to technical honesty, constructive review, and respect for contributors and users.

## Standards

- Focus on concrete technical evidence, reproducible behavior, and clear boundaries.
- Never publish credentials, private infrastructure details, or proprietary client data in issues, pull requests, or discussions.
- Respect licensing, attribution, and security reporting channels.

## Enforcement

Unacceptable behavior, including harassment, doxxing, or deliberate introduction of unsafe patterns, may result in removal of contributions and restriction from project spaces by the maintainers.
